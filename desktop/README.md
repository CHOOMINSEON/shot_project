# Windows에서 실행 파일 하나로 시작

검증한 [Windows 실행 파일 다운로드](https://github.com/CHOOMINSEON/shot_project/releases/download/desktop-windows-149a8233/IyoringCutStudio.exe)의 **IyoringCutStudio.exe**를 내려받아 더블클릭합니다. Docker·Python·FFmpeg를 따로 설치하거나 터미널 명령을 입력하지 않습니다. 먼저 기본 브라우저를 자동으로 열고 이 PC의 작업실에 로그인합니다. 자막 모델은 화면이 열린 후 별도로 준비하며, 상단에 준비 상태·받은 파일 크기·실패 시 재시도 버튼을 표시합니다.

- 사용 순서: **원본 업로드 → 예상 대본·연출 입력 → 대본대로 자동 편집 시작 → 실제 장면 후보 재생·선택 → 최종 편집본 다운로드**. 프로젝트는 자동 생성합니다. 같은 대사는 자동으로 연결하고, 음성이 없는 시각 후보는 원본을 확인한 뒤 선택하세요. 무음만 줄이려면 아래 **무음만 자동 편집하기** 메뉴를 사용합니다.
- 기본 기준은 −40dB 이하로 0.6초 이상 조용한 구간입니다. 음식 소리·대사·음악이 들리는 구간은 유지하며, 소리 앞 0.12초·뒤 0.2초 여유를 둡니다. 분석된 무음 시식·단면·제품 장면은 자동으로 보존하며, 추가로 남길 부분은 보존 구간으로 지정하세요. 배경음이 계속 있으면 감도를 조정하거나 직접 구간을 편집해 주세요.
- 완료 시 원본/편집본 길이와 삭제한 시간을 표시하고, 편집본 미리보기를 자동 생성합니다. 자동 편집 직후에는 **자동 편집 되돌리기**로 복원할 수 있습니다. 출력은 영상당 최대 30분이며, 그보다 길면 타임라인으로 확인하고 제품별·컷별로 출력하세요.
- Windows 10/11 64비트(x64)용입니다. ARM Windows·Mac용 실행 파일이 아닙니다.
- 첫 실행은 한국어 인식 medium 모델 약 1.5GB를 자동 다운로드하므로 인터넷과 설치 시간이 필요합니다. 이후 같은 PC에서는 준비한 모델을 재사용합니다.
- 자막 모델을 받는 중에도 영상 업로드·무음 자동 컷편집·기획·수동 컷 편집을 사용할 수 있습니다. 음성 인식은 준비 완료 후 활성화됩니다. 다운로드 중 `HF_TOKEN` 경고가 보여도 토큰 입력·가입·결제는 필수가 아닙니다.
- 브라우저가 자동으로 보이지 않으면 실행 창의 **접속 주소:** 다음에 나오는 주소를 복사해 Chrome/Edge 주소창에 붙여 넣습니다. 접속 주소는 이 PC에서 10분 동안 한 번 사용할 수 있으며, 자동 브라우저 진입과 따로 동작합니다.
- 이전 버전의 실행 창을 닫은 뒤 새 실행 파일을 켜세요. 원본·프로젝트·받은 모델은 보존합니다. 같은 PC에서 프로그램을 중복 실행하지 않습니다.
- RAM 16GB와 저장 공간 100GB 이상을 권장합니다. 10GB·2시간 원본 제한과 기존 자막 검수 기능을 유지합니다. 실제 10GB·2시간 고밀도 원본 전체 부하 검증은 아직 수행하지 않았습니다.
- 원본·프로젝트·모델·출력은 `%LOCALAPPDATA%\IyoringCutStudio`에 저장합니다. 실행 파일을 업데이트해도 이 데이터를 지우지 않습니다. 이 폴더는 별도 백업해 주세요.
- 켜진 프로그램 창을 유지하며 브라우저에서 작업합니다. 출력이 끝난 후 창을 닫거나 Ctrl+C로 종료합니다. 강제로 창을 닫으면 실행 중인 작업이 중단될 수 있습니다.
- 이 프로그램은 해당 PC에서 사용하는 작업실입니다. 다른 사람에게 공유할 공개 인터넷 주소를 자동 생성하지 않습니다. 로컬 시작 전용 일회용 로그인 주소는 다른 PC에서 사용할 수 없으며 서버 배포에는 활성화되지 않습니다.
- 소스는 이 저장소에 공개되어 있습니다. FFmpeg는 Gyan.dev의 공식 FFmpeg 홈페이지에 연결된 Windows 배포를 SHA-256 검증 후 포함합니다. FFmpeg GPL 라이선스와 빌드 정보는 실행 파일 내부의 `ffmpeg` 데이터에 포함됩니다.

## 대본과 연출로 자동 편집

**촬영 영상 업로드 → 예상 대본·연출 메모 입력 → 대본대로 자동 편집 시작 → 미리보기 확인 → 고화질 MP4 저장 → 다운로드** 순서입니다. 첫 화면에는 두 텍스트 입력만 표시하고, 세부 기획·자막 도구는 선택 메뉴로 접었습니다.

- 예상 대본은 한 줄에 한 문장씩 입력합니다. 영상에서 실제로 말한 대사를 찾아 대본 순서대로 연결합니다. 입력 원문을 임의로 고치거나 없는 대사를 합성하지 않습니다.
- 직접 녹음한 WAV·MP3·M4A·AAC·FLAC·OGG 파일은 **내 더빙 파일 추가**로 올립니다. 같은 대사가 더빙에 있으면 우선 사용하고 나머지는 촬영 원음을 사용합니다. 원음과 더빙을 한 편 안에서 섞을 수 있습니다.
- 더빙 화면은 촬영 원본의 동일 대사 장면, 대본·연출과 일치하는 영상 파일명, 업로드 순서로 연결합니다. 짧은 영상이 더빙보다 짧으면 반복해서 붙입니다. 제품·단면 등 장면을 의미적으로 이해하는 시각 AI는 포함하지 않으므로 미리보기에서 확인하세요.
- 연출 메모는 빠른 템포/긴 공백 줄이기, 9:16, 첫 문장 클로즈업/중앙 확대, 전체 화면, 흐린 배경을 반영합니다. 얼굴 추적, 음악·효과음·전환 효과 등 미지원 지시는 결과에서 별도로 표시합니다.
- 보내주신 CU 예시를 기본 대본으로 넣었습니다. `[제품명·실제 맛 평가]`, `[실제 결론과 이유]`는 실제 내용으로 채워 주세요. 비어 있거나 찾지 못한 대사는 표시하고 부분 미리보기만 만들며, 완성본 출력은 막습니다. 일치하는 대사가 전혀 없으면 기존 타임라인을 유지합니다.
- 대본과 실제 인식 대사를 결과에서 대조할 수 있습니다. 자막은 별도로 검수하며, 원음과 다른 숫자·부정 표현을 억지로 연결하지 않습니다. 입력 대본의 정규화된 유사도로 찾으므로 모든 자유로운 바꿔 말하기를 이해하는 시스템은 아닙니다.

GitHub Actions의 공개 저장소용 **표준 Windows 러너**로 빌드합니다. 빌드·테스트가 통과한 경우에만 실행 파일과 SHA-256을 Release에 게시합니다. 유료 러너·캐시·Actions 아티팩트 저장소·유료 호스팅을 사용하지 않습니다.


장면 검색 업데이트에서는 **대본대로 자동 편집 시작**이 원음과 영상 프레임/OCR을 함께 검색합니다. 처음 한 번 장면·한국어 OCR 모델 약 172MB를 별도로 받습니다. 말 없는 단면·시식도 후보로 보이며, **원본 구간 재생**으로 확인하고 선택하세요. **최종 편집본 다운로드** 버튼으로 MP4를 생성·저장합니다. 무음 컷은 분석된 음식 장면을 보존하고, 컷·순서를 바꾸면 자막 위치를 자동 동기화합니다. 제품명이나 개인 평가가 불확실하면 보조 후보로 표시합니다.
